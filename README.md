# serial-scanner

CDなどに付いてくる抽選応募のシリアルナンバーの紙を撮影して読み取り、応募先ごとにまとめる Web アプリ「シリアルスキャナー」です。
まとめたシリアルは10件ずつコピーでき、付属のブックマークレットで応募サイト（ticket.fortunemeets.app）のシリアル登録の入力欄へ貼り付けられます。

- **写真もシリアルも端末の外へ送りません。** 文字認識はブラウザの中（WebAssembly）で動き、読み取ったシリアルはそのブラウザにだけ保存します
- 1枚の写真に何枚の紙が写っていても、紙の向きがバラバラでも読み取れます
- 紙のタイトルから応募先を見分け、同じ応募先のシリアルをまとめます
- シリアルごとに写真の切り抜きを並べるので、読み違いがないか目で確かめられます
- ホーム画面に追加でき、一度開けば通信なしでも使えます

非公式のツールです。応募サイトの運営者とは関係ありません。

## 使い方

1. シリアルの紙を並べて撮るか、撮ってある写真を選びます（何枚でもまとめて選べます）
2. 読み取ったシリアルが応募先ごとに並びます。写真の切り抜きと見比べ、違っていれば直します
3. 「1〜10をコピー」を押し、応募サイトのシリアル登録の画面でブックマークレットを開いて貼り付けます
4. 入力欄の内容を確かめて、「シリアルナンバー登録」をご自身で押します

ブックマークレットは入力欄へ値を入れるだけで、登録ボタンは押しません。応募サイトは登録の失敗が続くとアカウントを一時的に使えなくするため、登録の前に必ず確かめてください。

## 仕組み

- **文字認識**: [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) の PP-OCRv4 を [ONNX Runtime Web](https://onnxruntime.ai/) で動かします。文字の行を検出し、傾きを直して切り出してから読みます。逆さまの行は確信度がほぼ0になるため、180°回して読み直します
- **応募先の見分け**: シリアルと同じ紙のタイトル（紙の向きで見た上にある、大きな文字の行）と、紙に印刷された応募サイトのURLを手がかりにします。タイトルの読み取りのぶれは文字列の似ている度合いで吸収し、数字の違うタイトル（「42nd」と「40th」など）は別の応募先として扱います
- **外部へ送らない仕組み**: バックエンドを持たない静的サイトです。モデルを含むすべてのファイルをこのサイトから配り、CSP（`connect-src 'self'`）で外部への通信を禁じています

設計の詳細は [docs/](docs/) にあります。

## 開発

Node.js 24 以上が必要です。

```sh
npm install
npm run dev        # http://localhost:5176
npm run build      # dist/ に出力
npx vite preview   # http://localhost:4176（Service Worker は本番ビルドでだけ動く）
npm test
npm run lint
npm run eval:ocr   # .local/fixtures/ の写真で読み取りを試す
```

作業の決まりは [AGENTS.md](AGENTS.md) にあります。実物のシリアルが写った写真は `.local/` に置き、Git に入れないでください。
