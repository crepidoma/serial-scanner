# 画面の確認

画面の変更は、型検査やビルドが通るだけで完了としない。ブラウザで実際に操作してから報告する。確かめられなかった場合は、その理由を報告に書く。

## 読み取りの画面

1. `npm run build` のあと `npx vite preview` で起動し、`http://localhost:4176` を開く（Service Workerとモデルのキャッシュは本番ビルドでだけ動く）。
2. スマートフォンの幅（390px程度）で確かめる。iPhoneのSafariに近いWebKitでも確かめる。
3. `.local/fixtures/` の写真を選び、シリアルと応募先が正しいこと、写真の切り抜きが出ること、外部への通信がないことを確かめる。`.local/e2e.cjs` があれば `node .local/e2e.cjs chromium` と `node .local/e2e.cjs webkit` で自動で確かめられる。
4. 写真は実物のシリアルが写っているため、Gitに入れない・スクリーンショットを共有しない。

## ブックマークレット

- 応募サイトの入力フォームの作りは、応募サイトのバンドルの `RegistrationEntry.tsx` にある（入力欄は `input#inputSerial1`〜、`maxLength` が桁数、「入力枠を追加」ボタン）。この作りに合わせて値を入れているため、変えたら同じ作りの再現ページで確かめる。
- 再現ページは React の状態の持ち方（`inputEl` を毎回コピーして `setInputEl`）まで真似る。値を入れたあとに1欄を手で直し、ほかの欄の値が消えないことも確かめる。
- 本物の応募サイトで確かめるときは、ログインを利用者に依頼する。登録ボタンは押さない。

## 注意

- ブラウザのダイアログ（alert）を開く操作は、ブラウザの自動操作を止めるため避ける。ブックマークレットは入力欄のないページで alert を出す。
