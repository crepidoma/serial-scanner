# 読み取りの確認

1. `npm test` で、判定の単体テスト（`tests/`）が通ることを確かめる。テストのシリアルは架空のものを使う。
2. `npm run eval:ocr` で `.local/fixtures/` の写真を読み取り、写真ごとのシリアル・確信度・応募先の手がかり・処理時間を見る。`--verbose` を付けると、シリアル以外の行（高さ・位置・向き・文字）も出る。応募先がずれたときは、まずこれで行の高さと位置を見る。
3. 変える前と後で、シリアルの件数・文字・応募先が変わっていないことを比べる。変わったら、どちらが正しいかを写真で確かめてから報告する。
4. 速さに関わる変更は、ブラウザ（WASM）でも測る（verify-ui）。Node.jsはブラウザより数倍速い。

## 注意

- 閾値を変えたら、その根拠（試した写真での値）を定数のコメントと `docs/architecture.md` に書く。
- 特定のアーティスト・企画の名前や形を判定に入れない。
- 写真を増やしたときは `.local/fixtures/` に置き、Gitに入れない。
