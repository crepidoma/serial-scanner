# 製品要件

## 目的

CDなどに付いてくる抽選応募のシリアルナンバーを、紙を撮影するだけで読み取り、応募先ごとにまとめる。まとめたシリアルを10件ずつコピーし、ブックマークレットで応募サイト（ticket.fortunemeets.app）の入力欄へ貼り付けられるようにする。

## 利用者

- 何十枚もシリアルの紙を持っていて、手で打ち込むのが大変な人。
- ITに詳しくない人も多い。スマートフォン（iPhone 11以降・最近のAndroid）が中心で、PCの人もいる。

## 約束すること

- **写真もシリアルも端末の外へ送らない。** 読み取りは端末の中だけで行う。画面の上部に常に書く。
- 応募サイトの登録ボタンは押さない。入力欄へ入れるまでを手伝い、確かめて押すのは利用者。

## 機能

| 機能 | 内容 |
| --- | --- |
| 読み込み | 写真を複数枚まとめて選ぶ、またはカメラで撮る。1枚に何枚の紙が写っていてもよく、紙の向きはバラバラでよい。 |
| 読み取り | 紙のシリアルを読み、同じ紙のタイトルと、紙に印刷されたURLのアーティスト部分を手がかりに応募先を決める。 |
| 応募先の振り分け | タイトルが似ている（読み取りのぶれを吸収）シリアルを同じ応募先にまとめる。タイトルが隠れた紙は、写真の中の応募先が1種類ならそれに、2種類以上なら利用者に選んでもらう。 |
| 確認 | シリアルごとに写真の切り抜きを並べる。確信度が低い・桁数がほかと違う・英数字以外を含むものに注意を出す。手で直す・消す・加えることができる。 |
| コピー | 応募先ごとに10件ずつコピーする（応募サイトが一度に10件まで受け付けるため）。コピー済みの印を付ける。 |
| ブックマークレット | 応募サイトのシリアル登録の画面で開き、貼り付けたシリアルを入力欄へ入れる。足りない入力欄は「入力枠を追加」を押して増やす。桁数の違うシリアルを知らせる。 |
| 保存 | シリアル・応募先・コピー済みの印を端末のブラウザに保存する。写真と切り抜きは保存しない。「すべて削除」で消せる。 |
| オフライン | ホーム画面に追加できる。初回に一度開けば、2回目からは通信なしで使える。 |

## 対象外

- 応募サイトへの自動登録、応募サイトへのログインの代行。
- サーバーへの保存、端末間の同期。
- 手書きのシリアル。
